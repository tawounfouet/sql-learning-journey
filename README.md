# sql-learning-journey

A personal SQL learning repo with two parts.

## `sql-book-analytics/`

Exercises from a SQL-for-data-analysis book. Each chapter has a README, table-creation scripts, query files and sample CSV data.

1. Chapter 1: Introduction
2. Chapter 2: Preparing Data for Analysis (date dimension)
3. Chapter 3: Time Series Analysis (US retail sales, loaded into Postgres via a notebook)
4. Chapter 4: Cohorts (legislators)
5. Chapter 5: Text Analysis (UFO sightings)
6. Chapter 6: Anomaly Detection (earthquakes)
7. Chapter 7: Experiment Analysis (game data)
8. Chapter 8: Creating Complex Data Sets (videogame sales)
9. Chapter 9: Conclusion

## `python-database/`

French-language notebooks on database management with Python, including a Datascientest course notebook. Also contains SQLite files (`musique.sq3`, `bd_test.sq3`) and four versions of a "chenil" (kennel) schema (`chenil_v1.sql` to `chenil_v4.sql`).
